# Demo Script

Target length: 60 to 90 seconds.

1. Open the landing page and explain the core problem: meetings end, but follow-through gets lost.
2. Toggle the theme once to show the light/dark system.
3. Open the sample workspace from the landing page CTA.
4. Point out that the demo is deterministic and does not use paid APIs.
5. Show the Overview tab with the executive summary, decisions, blockers, and open questions.
6. Open the Transcript tab and search for a keyword.
7. Open Action Items and point out inferred versus explicit work.
8. Open Ask AI and show a grounded answer with a timestamp.
9. Mention the private bucket, RLS, and protected processing route.
10. Close with the deployment URL once available.

## Recording

- Command: `npm run test:e2e:record-demo`
- Expected artifact folder: `test-results/`
- Recommended final upload destination: unlisted video host or the repository release assets
